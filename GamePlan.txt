■ 2. 今後の実装計画・進捗管理シート（ROADMAP）
================================================================================
※開発の手戻りを防ぐため、「物理・ギミック基盤 → 制作ツール統合 → レベル配置・ボス戦 → 総合研磨・通しテスト」の実効順序に再編して進行します。

--------------------------------------------------------------------------------
▼ Step 1: ゲームプレイ＆物理基盤の構築（コアサイクルの確立）
--------------------------------------------------------------------------------
目的: 敵の物理挙動を正常化し、停止トラップと幽霊・自機強化によるゲームプレイの核を完成させる。

[x] 1-1. 敵のビル貫通防止（Collision & Pushout）
    [x] 敵移動処理への MapRendererScript::GetBuildingPushout 連携
    [x] ビル壁面へのめり込み防止および外壁スライド迂回挙動の実装
    [x] 動的戦術スロット（自機壁際時の後方追従 Tail Follow / 開放地での先回り Interception）の実装
    [x] Context Steering（壁反発斥力）による事前カーブ回避の実装

[ ] 1-2. ステージギミック：拘束停止円トラップ（Restraint Circle）
    [ ] 円内侵入時の自機移動強制停止（3〜4秒間）処理の実装
    [ ] 拘束フィールド警告リング描画およびHUDカウントダウン警告演出

[ ] 1-3. 拘束連動エネミーラッシュ（Rush Wave）
    [ ] 停止と同時に死角・前方から複数体の敵が連続湧きするトリガー機構
    [ ] 足止め状態での360度包囲迎撃バトルのバランス調整

[ ] 1-4. 敵撃破時の幽霊化（AiState::Ghost）と視界妨害
    [ ] 撃破後の半透明ゴースト化とカメラ前方への浮遊追従
    [ ] プレイヤー照準を塞ぐ視界ジャミング（ノイズ・シルエット）演出

[ ] 1-5. 右クリック長押しによる幽霊吸収（Ghost Vacuum）
    [ ] 右クリックホールドによる吸引ビーム・収束パーティクル演出
    [ ] 吸引ゲージ蓄積によるゴースト成仏・消滅処理

[ ] 1-6. 経験値（EXP）獲得と自機アップグレード
    [ ] 霊魂吸収時のEXP蓄積およびレベルアップ処理
    [ ] 弾数増加・リロード短縮・攻撃力UP・HP回復などの強化オプション適用
    [ ] レベルアップ時・吸収時の爽快なHUDポップアップ演出

[ ] 3-2. Area 1 の配置（直線・カーブでの基本戦闘＋初級トラップ）

▼ Step 4: 総合研磨・通しテスト・最終バランス調整
